# 📬 ZipMailer

Минималистичная утилита для Android: следит за выбранными папками и **автоматически отправляет новые ZIP-архивы на email** через Gmail. Без экранов, кнопок «поделиться» и лишних телодвижений: положил архив в папку, и он уже в почте получателя.

> Приложение сделано для личных нужд (быстро пересылать архивы по работе) и выложено на случай, если пригодится кому-то ещё.

---

## ✨ Возможности

- 📁 **Несколько папок:** любые папки на телефоне, выбираются через системный диалог Android.
- 👥 **Несколько получателей:** письмо уходит всем сразу.
- 🔄 **Работа в фоне:** сервис с тихим уведомлением, проверка папок каждые 15 секунд.
- 🔌 **Автозапуск:** после перезагрузки телефона сервис стартует сам.
- 🛡️ **Только новые архивы:** то, что уже лежало в папке при добавлении, не отправляется.
- ⏳ **Ждёт, пока файл допишется:** недокачанный архив не уйдёт.
- 🔁 **Повтор при ошибке:** нет интернета или сбой, повторная попытка через 2 минуты.
- 🔐 **Данные зашифрованы:** пароль приложения хранится в `EncryptedSharedPreferences`.
- 🇷🇺 **Интерфейс на русском**, имена файлов с кириллицей работают.
- 📊 **Статус на экране:** видно, что делает приложение и почему не ушло письмо.

---

## 🧭 Как это работает

1. Ты выбираешь папки, получателей и вводишь данные Gmail.
2. Нажимаешь **Старт**: запускается фоновый сервис.
3. При первой проверке приложение запоминает уже лежащие ZIP как «старые».
4. Каждые 15 секунд оно ищет в папках новые `.zip` (подпапки не проверяются).
5. Когда размер файла перестал меняться, он отправляется письмом через SMTP Gmail.
   - **Тема** письма равна имени файла.
   - **Текст:** «Файл: имя».
   - **Вложение:** сам архив.
6. Отправленный файл запоминается и повторно не уходит.

## 📱 Требования

- Android 11 или новее (`minSdk 30`).
- Аккаунт Google с включённой **двухэтапной аутентификацией**.
- **Пароль приложения Google** (не обычный пароль от почты).

Проверялось на Motorola Edge 60 Pro (Android 17), включая автозапуск после перезагрузки. На других устройствах я не тестировал.

## 🚀 Установка и настройка

### 1. Получить APK

Собранного APK в репозитории нет, его можно собрать самостоятельно (см. раздел «Сборка» ниже).

### 2. Создать пароль приложения Google

1. Открой `myaccount.google.com/security` и включи двухэтапную аутентификацию.
2. Перейди на `myaccount.google.com/apppasswords`.
3. Введи имя (например, `ZipMailer`) и нажми «Создать».
4. Скопируй код из 16 букв. Повторно он не показывается.

### 3. Настроить приложение

1. Введи Gmail и пароль приложения, нажми **Сохранить**.
2. Нажми **Проверить вход в Gmail**. Должно появиться «Вход в Gmail выполнен ✔».
3. Добавь получателей кнопкой **Добавить**.
4. Нажми **Добавить папку** и выбери папку с архивами.
5. Нажми **Старт** и разреши уведомления.
6. Нажми **Настройки батареи** и поставь для приложения «Без ограничений». Без этого производитель телефона может убивать фоновый сервис.

> ⏱️ После нажатия «Старт» подожди секунд 20 и только потом клади тестовый архив в папку: при первой проверке приложение запоминает всё, что уже лежит в папке.

## 🛠️ Сборка

Исходный код проекта лежит в архиве `ZipMailer.zip` (проект Android Studio, Kotlin + Jetpack Compose).

### Вариант А: Android Studio

1. Распакуй архив и открой папку `ZipMailer` в Android Studio.
2. Дождись синхронизации Gradle.
3. **Build → Build APK(s)**. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант Б: GitHub Actions (прямо с телефона)

Компьютер не нужен: сборку делает облако GitHub.

1. Создай свой репозиторий и загрузи в него `ZipMailer.zip` (имя файла должно начинаться с `ZipMailer`).
2. Добавь файл `.github/workflows/build.yml` (текст ниже).
3. После коммита сборка запустится сама: вкладка **Actions** → последний запуск → раздел **Artifacts** → `ZipMailer-apk`.
4. Распакуй скачанный ZIP и установи `app-debug.apk`.

<details>
<summary>Содержимое build.yml</summary>

```yaml
name: Build APK
on: [workflow_dispatch, push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'
      - name: Install Gradle
        run: |
          for u in \
            https://services.gradle.org/distributions/gradle-8.11.1-bin.zip \
            https://downloads.gradle.org/distributions/gradle-8.11.1-bin.zip \
            https://mirrors.cloud.tencent.com/gradle/gradle-8.11.1-bin.zip \
            https://mirrors.aliyun.com/gradle/gradle-8.11.1-bin.zip
          do
            curl -fsSL --retry 5 --retry-delay 5 -o gradle.zip "$u" && break
          done
          unzip -q gradle.zip -d "$HOME"
          echo "$HOME/gradle-8.11.1/bin" >> "$GITHUB_PATH"
      - run: |
          unzip -q ZipMailer*.zip
          cd ZipMailer
          gradle assembleDebug --no-daemon
      - uses: actions/upload-artifact@v4
        with:
          name: ZipMailer-apk
          path: ZipMailer/app/build/outputs/apk/debug/app-debug.apk
```

</details>

> ⚠️ Облачная сборка каждый раз подписывается новым отладочным ключом. Чтобы установить новую версию, **сначала удали старую** (настройки придётся ввести заново).

## ⚠️ Ограничения

- Проверяются только файлы прямо в выбранной папке, **подпапки нет**.
- Архивы **больше 18 МБ пропускаются** (лимит вложения Gmail 25 МБ, плюс накладные расходы кодирования).
- Все получатели получают одно письмо и видят адреса друг друга.
- В памяти хранятся последние 1000 отправленных файлов. Если в папке больше тысячи ZIP, самые старые могут уйти повторно.
- У Gmail есть суточный лимит на отправку писем.
- Если приложение убьют ровно между отправкой и записью в список, письмо может уйти дважды.
- Файл с тем же именем, но другим размером или временем изменения, считается новым.

---

## 🔒 Безопасность и приватность

- Gmail, пароль приложения, получатели и список отправленного хранятся **только на телефоне** в зашифрованном виде.
- Резервное копирование Android для приложения отключено.
- Данные передаются только на `smtp.gmail.com` (порт 587, STARTTLS).
- Приложение читает только выбранные папки и ничего в них не меняет и не удаляет.
- Пароль приложения даёт право отправлять почту от твоего имени, но не открывает аккаунт целиком. Отозвать его можно в любой момент на `myaccount.google.com/apppasswords`.
- Никому не показывай свой пароль приложения.
